# GitHub - ViktorRingnes/hackernews: hacker news cli tool · GitHub

hackernews
==========

hacker news in the terminal

install
-------

```
cargo install hackernews
```

usage
-----

run `hackernews`, or: `hackernews new`, `hackernews best`, `hackernews ask`, `hackernews show`, `hackernews jobs`.

keys: `j`/`k` move, `h`/`l` page, `enter` open, `c` comments, `space` fold, `/` search, `y` yank, `?` help, `q` quit
