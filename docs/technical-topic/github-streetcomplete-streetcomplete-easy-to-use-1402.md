# GitHub - streetcomplete/StreetComplete: Easy to use OpenStreetMap editor for Android · GitHub

[![StreetComplete](/streetcomplete/StreetComplete/raw/master/.github/images/feature_graphic.png)](/streetcomplete/StreetComplete/blob/master/.github/images/feature_graphic.png)

### >>> [Test on iOS TestFlight now!](https://testflight.apple.com/join/K1u3eUU5)

StreetComplete is an easy to use editor of OpenStreetMap data available for Android and iOS. It can be used without any OpenStreetMap-specific knowledge. It asks simple questions, with answers directly used to edit and improve OpenStreetMap data. The app is aimed at users who do not know anything about OSM tagging schemes but still want to contribute to OpenStreetMap.

StreetComplete automatically looks for nearby places where a survey is needed and shows them as quest markers on its map. Each of these quests can then be solved on site by answering a simple question. For example, tapping on a marker may show the question "What is the name of this road?", with a text field to answer it.
More examples are shown in the screenshots below.

The user's answer is automatically processed and uploaded directly into the OSM database. Edits are done in meaningful changesets using the user's OSM account.
Since the app is meant to be used on a survey, it can be used offline and is
economic with data usage.

To make the app easy to use, quests are limited to those answerable by asking simple questions.

* See the [latest release notes](https://github.com/streetcomplete/StreetComplete/releases).

Contributing
------------

This is an active open-source project, so you can get involved in it easily!
You can do so **without any programming or OpenStreetMap knowledge**! Just choose a task that you like.

Here are a few things you can do:

* 🐛 [Test and report issues](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md#testing-and-reporting-issues)
* 📃 [Translate the app into your language](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md#translating-the-app)
* 🕵️ [Solve notes left by StreetComplete users](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md#solving-notes)
* 💡 [Suggest new quests](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md#suggesting-new-quests), or, even better, [implement them](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md#developing-new-quests).
* ➕ [and more…](/streetcomplete/StreetComplete/blob/master/CONTRIBUTING.md)

Also, if you like StreetComplete, **spread the word**! ❤️
