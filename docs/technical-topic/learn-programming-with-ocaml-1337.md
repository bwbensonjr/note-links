# Learn Programming with OCaml

Learn Programming with OCaml
============================

by [Sylvain Conchon](https://usr.lmf.cnrs.fr/~conchon/) and
[Jean-Christophe Filliâtre](https://usr.lmf.cnrs.fr/~jcf/)
----------------------------------------------------------------------------------------------------------------------

This book on [OCaml](https://ocaml.org/)
is an English translation
(by [Urmila Nair](https://www.aropefastenedbetween.fr/))
of
[this book in French](https://usr.lmf.cnrs.fr/programmer-avec-ocaml/).
The translation was funded by
[The OCaml Software Foundation](https://ocaml-sf.org/).
The book is openly licensed via
[CC BY SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en).

* [Get the book](lpo.pdf) (1.9Mb PDF file)
* [Get the book](lpo.epub) (2.3Mb EPUB file)
* [Get the code](code.html)

Typos and errors can
be [reported here](https://github.com/backtracking/learn-programming-with-ocaml/issues).
